# MyFit — MY Kcals Notebook

MyFit is an AI-powered calorie and nutrition tracker built as a native Android app. Describe your food to get estimated calories and macros, then track your daily nutrition.

## Tech Stack

* Kotlin
* Jetpack Compose
* Room Database
* Android SDK
* Gradle
* AI-powered nutrition analysis

## Project Structure

```text
MyFit/
```
